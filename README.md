## Français

Calendriers des [bains libres](https://peps.ulaval.ca/activite/bains-libres) du PEPS de l'Université Laval, prêts à ajouter dans Google Agenda, Apple Calendrier ou Outlook. Aucune installation requise.

### Comment s'abonner

1. Ouvrez la [page d'abonnement](https://xiyuez1.github.io/UL-PEPS-piscine-subscription/) et copiez le lien du calendrier voulu.
2. Dans Google Agenda, à côté de « Autres agendas », cliquez sur **+**, puis **À partir de l'URL**.
3. Collez le lien et cliquez sur **Ajouter un agenda**.

Six calendriers sont offerts : toutes les longueurs, piscine olympique, piscine avec tremplins, couloirs de 25 m ou plus, couloirs de 50 m, et bains pour tous.

Les calendriers se mettent à jour chaque nuit vers 2 h. Google actualise les agendas abonnés environ une fois par jour.

### Fonctionnement

Chaque nuit, GitHub Actions télécharge l'horaire du PEPS et le convertit avec le programme de [UL-PEPS-piscine-calendar](https://github.com/XiyueZ1/UL-PEPS-piscine-calendar). Pour utiliser ce programme sur votre ordinateur, consultez ce dépôt.

### Avis

Projet personnel, sans lien avec l'Université Laval ni le PEPS. Vérifiez toujours l'[horaire officiel](https://peps.ulaval.ca/activite/bains-libres) avant de vous déplacer.

Code écrit avec l'aide de Claude (Anthropic).

<a name="english"></a>
## English

Calendars of the PEPS [swimming pool schedule](https://peps.ulaval.ca/activite/bains-libres) at Université Laval, ready to add to Google Calendar, Apple Calendar or Outlook. No installation needed.

### How to subscribe

1. Open the [subscription page](https://xiyuez1.github.io/UL-PEPS-piscine-subscription/) and copy the link of the calendar you want.
2. In Google Calendar, next to "Other calendars", click **+**, then **From URL**.
3. Paste the link and click **Add calendar**.

Six calendars are available: all lap swims, Olympic pool, diving pool, lanes of 25 m or longer, 50 m lanes, and family swims.

The calendars update every day around 2 am. Google refreshes subscribed calendars about once a day.

### How it works

Every night, GitHub Actions downloads the PEPS schedule and converts it with the program from [UL-PEPS-piscine-calendar](https://github.com/XiyueZ1/UL-PEPS-piscine-calendar). To run that program on your own computer, see that repository.

### Disclaimer

Personal project, not affiliated with Université Laval or PEPS. Always check the [official schedule](https://peps.ulaval.ca/activite/bains-libres) before you go.

Written with the help of Claude (Anthropic).

## 中文

拉瓦尔大学 PEPS [游泳池开放时间表](https://peps.ulaval.ca/activite/bains-libres)的订阅日历，可以直接添加到 Google 日历、Apple 日历或 Outlook。

### 如何订阅

1. 打开[订阅页面](https://xiyuez1.github.io/UL-PEPS-piscine-subscription/)，复制想要的日历链接。
2. 在 Google 日历左侧“其他日历”旁点 **+**，选 **通过网址添加**。
3. 粘贴链接，点 **添加日历**。

一共有六个日历：所有游泳场、奥林匹克池、跳板池、25 米及以上泳道、50 米泳道、家庭场。

日历每天夜间自动更新。

### 工作原理

每天夜间，GitHub Actions 会下载 PEPS 的时间表，用 [UL-PEPS-piscine-calendar](https://github.com/XiyueZ1/UL-PEPS-piscine-calendar) 里的程序转换成日历。想在自己电脑上运行该程序，可直接下载。

### 说明

个人项目，与拉瓦尔大学和 PEPS 没有关联。出发前请查看[官网时间表](https://peps.ulaval.ca/activite/bains-libres)确认。

代码在 Claude（Anthropic）的协助下编写。
